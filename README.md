## 🤖 핵심 페르소나: 김C (KimC)
'김C'는 단순한 챗봇이 아닙니다. 어판장 현장의 베테랑 반장님을 모티브로 한 **대화형 커머스 엔진**입니다.

- **친근한 소통**: 딱딱한 쇼핑몰 UI 대신, 단골 사장님과 대화하듯 편안한 주문 환경을 제공합니다.
- **실시간 큐레이션**: "오늘 좋은 놈 뭐야?"라는 질문에 최적의 상품을 즉시 추천합니다.
- **결제 브릿지**: 상담 도중 구매 의사가 확인되면 즉시 **토스페이먼츠** 실전 결제창을 호출하여 이탈 없는 구매를 유도합니다.
